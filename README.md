
# Rabbits & Wolves · 수업용 프로토타입

요청 사양을 반영한 독립 구현 버전입니다.

### 포함 기능
- 모의실험 페이지
- 생존 게임 페이지
- 캡처 + 해석 제출 페이지
- 좌측 격자형 실시간 생태계
- 우측 조작 공간
- 하단 양축 개체수 그래프
- 실시간 생태 피라미드
- 3차 소비자 옵션
- 붉은여우 독립 포식자 옵션
- 4차 소비자 없음
- 학생 조작 변인 6개만 제공
- 해석 대신 관찰 포인트만 제시
- Apps Script + Sheets + Drive 제출 예시

원본 HAFS 저장소 코드를 복사하지 않고 새로 작성한 프로토타입입니다.
