# Rabbits & Wolves · 수정 버전

이번 수정 사항
- 모의실험/게임 모두 3차 소비자와 붉은여우를 ON/OFF 대신 초기 개체수 슬라이더로 조절
- 모의실험: 3차 소비자 0~15, 붉은여우 0~20
- 생존게임: 3차 소비자 0~10, 붉은여우 0~15 + 예산제
- 게임 생존 압박 강화, 최대 250 STEP
- 그래프는 STEP 0부터 현재/종료 STEP까지 전체 누적 기록 표시
- 양축 그래프 유지
- 제출 화면의 Apps Script 안내 문구 제거
- 제출 버튼 문구를 단순히 '제출'로 변경

GitHub Pages에는 폴더의 파일들을 기존 저장소 최상위에 덮어써서 업로드하면 됩니다.
